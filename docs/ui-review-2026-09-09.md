# 게임 UI 개선

## 변경

- 목표창은 현재 목표를 우선 표시하고 공물 목록은 기본 접힘으로 바꿨다. 사용자가 명시적으로 펼쳐 둔 설정은 유지한다. O 키 표시와 aria-expanded/controls를 연결했다. 이야기의 화자별 서체와 목표 왜곡 연출은 유지한다.
- 긴 상호작용 문구는 줄바꿈하며 HUD 배율을 반영해 좌우 경계 안에 둔다. 화면 위로 잘리면 표지점 아래에 표시한다. 조사 기록 버튼과 손거울 안내의 위치를 분리했다.
- 자막의 크기/행간/배경 대비와 선택지 클릭 영역을 정리했다. 선택지 높이 제한은 HUD 배율을 반영한다.
- 일시정지는 화면 / 소리와 언어 / 안내 및 접근성으로 묶었다. 계속하기를 우선 배치하고 새 게임·종료를 구분했다. 음량 수치, 슬라이더 이름, 토글/프리셋의 선택 상태, 키보드 포커스 표시를 추가했다.
- 소지품은 더 큰 설명 영역과 닫기 버튼, 반응형 6열/4열 슬롯을 사용한다. 제목/힌트/선택 상태를 정리했다.
- 조사 기록에 발견한 장소별 필터와 기록 수를 추가했다. 미발견 장소는 필터에 노출하지 않는다. 필터 변경 시 포커스를 보존하고 기록 스크롤을 처음으로 옮긴다. 본문 크기/명도/행간을 높였다.
- 타이틀 설정과 각 메뉴에 동일한 패널·테두리·포커스 스타일을 적용했다. 닫힌 설정/소지품은 접근성 트리에서도 숨긴다. 고대비/모션 감소 설정을 유지하고 전체 화면 블러를 줄였다.

표현 스타일은 `src/ui/presentation.css`이며 기존 스타일 뒤에 로드한다. 새로운 이미지나 WebGL 패스는 추가하지 않았다.

## 검증

- 타입 검사, diff 공백 검사, 기존 자동 테스트 104개, 데스크톱 콘텐츠 빌드 통과.
- 실제 PauseMenu/InventoryUI/EvidenceJournal을 사용하는 격리된 컴포넌트 페이지에서 검수했다. 573px 및 320px 설정 패널의 가로 넘침 없음, 이름 없는 슬라이더 0개를 확인했다.
- 실제 고대비/화질 버튼 클릭, 계속하기, 기록장 열기/닫기를 실행했다. 공동우물 필터 선택 시 제목이 공동우물 하나로 제한되고 11개 기록만 표시됐다. 미발견 장소는 없었으며 닫힌 설정의 visibility는 hidden이었다.
- 실제 게임 우물 장면에서 새 목표창이 환자복/옷걸이를 가리지 않고 목록이 접혀 있는 것을 확인했다.
- 마지막 Mac 네이티브 UI 검수 시 화면이 잠겨 CUA가 작업을 거부했다. 따라서 **이번 UI 변경의 네이티브 시각 검수는 미완료**다. 이전 아트 변경의 네이티브 검수와 구분한다. Windows 실기기 검수도 수행하지 않았다.
- UI 체크용 페이지는 `artifacts/screening/ui-review.html`, 직접 버튼 검수는 `ui-review-scene.html`이다. 포트 5187 전용이며 사용자 게임 저장에는 접근하지 않는다.
