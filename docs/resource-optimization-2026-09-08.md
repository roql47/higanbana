# 추가 리소스 최적화 — 2026-09-08

후속 작업: [2026-09-09 환경음 구간 재생·실내 가림 처리](./resource-optimization-2026-09-09.md). 아래 내용은 당시 상태다.

오디오를 구간별로 준비·회수하고, 학교·여관·저택의 실물 가구를 접근 시 로딩하도록 바꿨다. 조사점 검색과 일반 요괴의 경로 탐색·애니메이션 갱신 비용도 줄였다. 전체 RAM/GPU 사용량이나 전후 FPS 개선율은 측정하지 않았다.

오디오의 **64MiB는 캐시 정리 목표**다. 현재 구간과 재생 중인 소리는 보호하므로 이 값을 초과할 수 있다. 실제 테스트의 공통 마을 오디오만으로도 목표를 넘었다. 전체 RAM 상한이나 오디오 전체의 강제 상한으로 해석하면 안 된다.

가구 스트리밍의 소유 범위는 새로 로드한 실물 모델·텍스처·재질·기하와 그 복제다. 건물 셸, 충돌체, 조사점, 스토리 객체를 포함한 전체 월드를 언로드하는 구현은 아니다. 로딩 실패와 떠난 뒤 늦게 완료한 로딩에서도 해당 배치의 자원을 정리한다.

## 검증

- 자동 테스트 52개 통과. 오디오 요청 중복·동시 디코딩 제한·LRU·재생 중 보호·종료 후 해제·늦은 완료, 지역 가구의 로딩/해제 유예·부분 실패·공유 자원 단일 해제·재진입, 공간 격자 결과와 선형 검색의 일치, 경로 대기열, 기존 시야각 판정과의 일치를 검증했다.
- 게임 및 scripts 타입 검사, `/higanbana/` 경로의 프로덕션 빌드, `git diff --check` 통과. 기존 main 청크 용량 경고는 남아 있다.
- 별도 `127.0.0.1:5187` 테스트 주소에서 실제 게임과 요괴 2개를 실행했다. 출발점에서는 세 가구 배치가 모두 비상주였고, 각 건물 접근 시 해당 배치가 로드됐다. 학교의 실물 가구가 렌더링되는 것도 확인했다.
- 여관 접근 시 거울 장면의 직계 자식 수는 14 → 15, 이탈 후 14, 재진입 후 15였다. 새 가구 배치 그룹이 추가·제거·재생성되는 것을 확인한 수치이며 메시 개수나 VRAM 사용량은 아니다.
- 테스트 조작으로 출발점에 복귀한 뒤 **해제 유예에만 13초의 시간을 전달**하여 세 배치가 비상주로 돌아오는 것을 확인했다. 실제 13초 플레이나 장시간 안정성 시험은 아니다.
- 초기 마을의 오디오 상주 키는 29개, 우물 접근 후 37개, 이탈 및 재생 종료 후 다시 29개였다. 학교 전용 키도 접근 후 준비되고 이탈 후 회수됐다. 압축 바이트 캐시는 준비 완료 후 0이었다. 실제 브라우저의 네이티브 루프를 종료한 뒤 해당 보이스의 버퍼 참조가 `null`인 것을 확인했다.
- 확인한 브라우저 세션에 경고·오류 로그가 없었으며 요괴 두 개가 계속 순찰했다. 추격 전체·모든 스토리 ACT·Windows 패키지는 이번 검증 범위에 포함하지 않았다.

## 남은 최적화 후보

1. **긴 배경음 스트리밍**: 현재 47초·80초 등의 앰비언스는 계속 전체 PCM을 사용한다. 필요한 루프·크로스페이드 동작을 보존하면서 스트리밍 재생을 도입하면 상주 오디오 RAM을 더 줄일 여지가 있다.
2. **구간 단위 월드 관리와 실내 가시성**: 이번 가구 배치를 넘어서 건물·효과까지 로딩 단위를 넓히거나 방·출입구 기준 가시성 판정을 도입할 수 있다. 원거리 거울·카메라 연출과 스토리 참조도 함께 처리해야 한다.
3. **GPU 압축 텍스처 확대**: 기존 KTX2 선택 경로는 주요 모델 일부에 적용되어 있다. 나머지 큰 텍스처를 대상으로 시각 품질·호환 폴백을 확인하며 범위를 넓힐 수 있다.
4. **긴 단일 경로 탐색 분할**: 이번 큐는 동시 A* 실행 집중을 줄인다. 개별 탐색 자체가 길어지는 맵에서는 프레임별 확장 노드 예산이나 계층형 경로 탐색을 추가 검토할 수 있다.

위 후보를 모두 도입해야 출시할 수 있다는 뜻은 아니다. 현재는 웹 실행과 빌드까지 검증했으며, Windows 패키지에서 실제 GPU·메모리·장시간 플레이를 확인하는 출시 검증이 남아 있다. 연출·오디오 일시정지, 설정 저장, 오프라인 패키징 등 기능 항목은 [Steam 스크리닝](/Users/jay/Claude/3D_motion/docs/steam-screening-2026-09-08.md)을 참고한다.
