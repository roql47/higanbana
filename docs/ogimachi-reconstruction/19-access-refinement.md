# 진입로 보정 결과

- 12개 장소 진입 후보를 건물 외곽 경계에서 1m 여유를 둔 사각형 장애물로 검사했다.
- 이전 건물 교차 5곳을 우회 경로로 대체. 사당 중심은 기존 초안에서 12m 이동했다.
- 기존 건물을 활용하는 4곳은 건물 중심이 아니라 외곽 접근점에서 진입 경로를 시작한다. 실제 문 위치는 제작 시 확정해야 한다.
- 모든 진입선의 건물 교차는 0. 실제 캐릭터 충돌/카메라/길 폭 검증 완료를 뜻하지 않는다.
- 기존 도로 경사가 25% 이하인 연결을 우선 탐색했지만 이전의 급경사 연결 6개에는 대체 경로가 없었다. 지형 공사 또는 장소 재배치 검토가 필요하다.
- 공동우물 진입 경로는 약 103m로 길어 부지 재검토 대상으로 남긴다.
- 지도 하늘색 선은 새 진입 후보, 주황색 선은 경사 검토가 남은 도로 후보다.

## 검증

단위 검사 5개 통과: 장애물 우회, 점유된 부지 중심 이동, 기존 건물 외곽 접근점, 선택 경계 제한, 선분-사각형 충돌.
실제 데이터 12개 진입선의 확대 건물 경계 교차 및 유지 범위 검사 통과.

## 다음 작업

급경사 구간의 실제 게임 지형과 다리/계단을 확인하고, 우물과 논길 진입을 짧게 만드는 부지 조정. 실제 맵 건물 모델이나 지형은 이번 단계에서 수정하지 않았다.
