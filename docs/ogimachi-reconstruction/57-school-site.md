# 폐교 공간 구성 · 후속 모델링 인계

2026-09-13. 사용자 요청: 다음 건물 제작 재개. 기존 사당·사진 비교 기능은 유지했다.

## 적용

- 기존 `src/world/higasato/school.ts`의 학교 외피·교실·복도·교무실·준비실·방송실·책상·피아노·신발장을 재사용했다. 이번 작업에서 건물 전체를 신규 모델링하거나 Blender 편집본을 새로 만든 것은 아니다.
- `schoolSiteBuild.ts`가 독립 플레이와 배치 검토 화면의 공통 조립 함수다. 서쪽 진입 공간에 낮은 울타리와 학교 안내 표지를 추가했다. 기둥은 충돌을 가지며 가운데 출입 통로를 비운다. 울타리 가로대에는 별도 충돌이 없다.
- 중심 `(-336.575,-359.589)`, 외피 약 27×14m, 정면 -X. 외부 스폰 `(-355.575,-359.589)`, 기존 현관 앞 `(-351.575,-359.589)`.
- 마루는 부지 기준 +0.33m. 기존 학교 부지 평탄화를 `layout=1`에도 적용해 배치 검토와 독립 플레이의 높이 처리 차이를 줄였다.
- 시작 시 미오가 현관 쪽을 바라보게 했다. 출입 버튼은 기존 순간 이동 방식이다.
- 기존 5개 조사 지점에 준비실 크레용 그림과 책상 이름표를 추가했다. 총 7곳이며 ACT 8–9 단서 수집/추격 규칙은 연결하지 않았다.
- `story-layout.json`의 북쪽 입구 후보는 실제 모델 서쪽 현관과 다르므로 현관/스폰 좌표를 수정하고 기존 도로 경로를 `needs-recompute`로 표시했다. 이전 path/audit는 과거 후보 기록이다.

## 다른 세션에서 유지할 기준

학교 본체는 월드 좌표로 생성된다. 별도 GLB로 교체할 경우 중심·정면·마루 높이를 맞추고 `SchoolInterior`가 공개하는 조사 좌표, 복도 문, 은신 위치, 실내 경계를 함께 보존해야 한다. 책상 재배치 시 이름표와 추격 관련 좌표도 함께 옮긴다. 2층은 현재 외관/막힌 계단 연출이며 자유 탐색 가능한 2층으로 보고하지 않는다.

새 울타리·표지는 공간 구성용이다. 상세화는 실제 재질/이음부/노후 표현을 다른 세션에서 보강한다. 실제 폐교 사진을 복원한 결과로 주장하지 않는다.

## 검증과 남은 일

- 타입 검사와 지도 빌드 통과. 큰 번들 경고는 남아 있다.
- 건물 및 서쪽 진입 공간을 0.5m 간격으로 검사: 선택 keep 범위 밖 0, 원래 교체 대상 필지 435719872를 제외한 주변 건물과 중첩 0.
- 브라우저에서 외부 스폰/울타리/현관 및 버튼 실내 진입, 신발장 조사 버튼 활성화 확인.
- 브라우저 관찰 약 16 FPS, 1847 draw calls, 3204k triangles. 초기 로딩 수치와 구별했지만 정식 성능 측정은 아니다. 실내외 표시 범위와 기존 소품 드로우콜 최적화가 필요하다.
- 계단을 걸어서 통과하는 왕복, 조사 7곳의 실제 접근, 도로부터 현관까지 연속 이동은 미검증이다.
- ACT 8–9 진행 및 새 사진의 플레이 배경 합성은 이번 범위에 포함하지 않았다.
