# B003 전승관 정면 세부 구조 보강

2026-09-13. 기존 v2를 별도 Blender 장면으로 복사해 정면의 근접 디테일을 보강했다.

- 층간·창 하부 목재 띠를 짧은 판재로 분할하고 기둥 연결판과 체결부를 추가했다.
- 하층 창문에 이중 레일, 중앙 창틀, 잠금장치와 손잡이를 추가했다.
- 출입구 손잡이와 슬라이딩 레일, 처마 하부 받침과 마감 체결부를 추가했다.
- 화분의 덩어리형 잎을 접힌 면을 가진 입체 잎 114개로 교체했다.
- 기존 창 배열, 커튼, 바구니 진열대, 목재·석재 재질과 배치를 유지했다.

새 사진 대조나 실측 없이 기존 정면 관찰 기록을 바탕으로 구조를 추정해 보강한 단계다. 후면과 실내는 이번 작업 범위가 아니다. 간판 글씨는 게임의 별도 레이어를 사용한다.

Blender 렌더 2장을 확인하고 실제 지도에서도 정면과 간판 표시를 확인했다. 타입 검사 및 지도 빌드 통과, 배포 폴더에 v3 모델 포함 확인. 기존 대용량 청크 경고는 남아 있다.

모델은 6,375,408 bytes로 v2의 3,811,536 bytes보다 약 67% 커졌다. 재질별 병합으로 메시 13개와 텍스처 4개는 유지했다. 파일 크기 증가를 실제 프레임 비용과 동일하게 보지는 않으며 이번 단계에서 FPS 비교 측정은 하지 않았다.
