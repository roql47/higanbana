# 공동우물 지상부 1차

검토: `/ogimachi.html?view=detail&layout=1&site=well&clean=1`

Blender에서 고리형 돌 테두리 4단, 목재 지지대, 권양기 축과 감긴 밧줄, 수직 밧줄, 손잡이, 양동이, 디딤돌을 제작했다. 지상부 GLB 1,029,192 bytes. 원본 `assets/authored/ogimachi/Story-well.blend`.

현재 위치 (-86,-87)에 검토 화면 전용으로 배치했다. 우물 테두리는 실제 구멍이 있는 메시지만 아래 지형을 뚫지는 않았다. 바닥의 어두운 수면은 지하 공간을 대신하는 임시 표현이며 실제 12m 수직 공간은 미제작이다.

TypeScript·빌드 통과, 브라우저에서 지지대·밧줄·고리형 테두리·양동이 표시 확인. 디딤돌의 경사 지면 접합, 석재 질감·노후 마감, 지하·충돌·스토리 상호작용은 후속 작업이다.
