# 기존 맵 사당·학교 에셋 이식

## 적용
- 기존 Hokora와 SchoolInterior 생성 코드를 재사용해 story-layout의 사당·학교 좌표에 건물과 내부 소품을 함께 생성한다.
- 생성 원점을 변경하므로 상호작용 좌표와 충돌체도 같은 위치에 생성된다. 기존 맵 호출은 기본 원점을 유지한다.
- 학교 상세 모델을 기다린 뒤 내부 보기 화면을 표시한다. 로드 실패 시 화면에 기본 모델 표시임을 알린다.
- 배치 확인 화면의 기존 학교 자리 건물 435719872를 제외해 중복 외피를 방지한다.
- 배포용 파일 목록에 필요한 모델·텍스처 27개를 추가했다.

## 확인
- 타입 검사 및 오기마치 빌드 통과.
- 브라우저에서 학교 방송실과 사당 제단의 기존 소품·텍스처 표시 확인.
- 화면 하단의 기존 학교 내부 / 기존 사당 내부 버튼으로 이동 가능.

## 남은 작업
- 이번 적용은 layout=1 배치 확인 화면이다. 기본 플레이와 전체 액트에 아직 연결하지 않았다.
- 주변 지형과 출입구 높이 및 도로 접근 경로를 맞춰야 한다. 충돌체 생성 자체와 실제 보행 검증은 다르다.
- 기존 학교·사당의 문, 아이템, 액트 진행 상태를 플레이 루프에 연결해야 한다.
- 나머지 저택·여관 등도 원본 에셋을 우선 재사용한다.
