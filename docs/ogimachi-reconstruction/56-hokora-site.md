# 오래된 사당 · 부지와 건물 배치 인계

2026-09-13. 사용자 역할 분담에 따라 상세 모델을 새로 만들지 않고, 기존 사당 구조와 소품을 재사용해 다음 장소의 공간을 구성했다.

## 실제 적용

- 기존 예정점 `(-498,-600)`은 현 사당 외곽과 도로가 겹친다. 건물/도로를 지우는 대신 사당을 빈 공간 `(-535,-585)`로 옮겼다.
- 동쪽 정면, 건물 14.8×11.6m, 기단 약 16.8×13.6m. 실제 기반은 `src/world/higasato/hokora.ts`의 기존 절차형 건축/에셋 조합이다. 이번에 새 Blender 편집본을 만든 것은 아니다.
- 수평 부지와 8m 외곽 완화 구간을 만들고, 북쪽 기존 도로에서 들어오는 폭 2.4m 흙 참배길을 추가했다.
- 길: `(-511.821,-564.119)` → `(-521,-571)` → `(-523,-585)` → 동쪽 계단. 연결 도로 ID `114217157`.
- 기존 마루·계단·문·네 기둥·제단·석등·촛대·에마·금줄 세 곳·아이 흔적을 유지했다.
- 기존 `public/models/props/offer-suzu.glb`를 높이 0.12m로 제단의 `suzuPos`에 배치하고 배포 목록에도 등록했다.
- 독립 사당 플레이, 전승관/신사 플레이와 스토리 월드에서 같은 조립 함수를 재사용한다.

## 상세 모델링 계약

건물 기준점은 `HOKORA_SITE`와 `story-layout.json`의 새 위치를 일치시킨다. 바닥은 기준 지면 +0.42m. 동쪽(+X) 문 폭 2.8m와 계단을 유지한다. 제단, `suzuPos`, `wardPositions[0..2]`, `childMarkPos`, `chaseArena`는 사당 생성자가 함께 계산하므로 상세화할 때 위치를 별도로 추정해 복제하지 않는다.

- 기반 건물/소품: `src/world/higasato/hokora.ts`
- 부지·길의 높이 계약: `src/world/ogimachi/hokoraSite.ts`
- 조립·방울·참배길·안내판: `src/world/ogimachi/hokoraSiteBuild.ts`
- 독립 플레이와 조사 표시: `src/world/ogimachi/legacySitePlay.ts`
- 상세화 참고: `public/models/props/hokora-altar.glb`, `hokora-kyodai.glb`, `ema-rack-frame.glb`, `shimenawa-binding.glb`, `shimenawa-loose.glb`, `offer-suzu.glb`.

붉은 방울은 현재 배치 소품이다. 획득 아이템을 연결할 때 같은 위치에 두 번째 방울을 만들지 말고, 이 소품의 표시/제거 상태를 획득 상태에 연결한다. 건물 출입문은 공간 검수용으로 열려 있다.

## 검증

- 건물 기반 및 참배길 샘플이 사용자 유지 영역 안에 있고 기존 건물 폴리곤과 겹치지 않는 검사 통과.
- 건물 바닥 지형의 수평 유지, 원거리 지형 불변, 참배길 연결 높이 검사 통과 (`tests/hokora-site.test.mjs`).
- DEM 기준 부지 높이 약 -8.625m, 도로 접점 -9.236m, 설계 길 중심선 최대 경사 약 3.6%. 전체 경로의 실제 보행 완주를 의미하지 않는다.
- 게임 화면에서 동쪽 계단/정면과 실내 제단·기둥 배치 확인. 실내 위치 확인 버튼은 검수용 이동이며 이것을 계단 보행 검사로 간주하지 않는다.
- 타입 검사와 지도 빌드 통과. 이전 이로리 v4 파일 누락은 이번 빌드에서는 발생하지 않았다.
