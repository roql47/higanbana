# 실제 맵 위 3D 공간 검토

`/ogimachi.html?view=detail&layout=1`에서 배치도를 실제 맵 위에 표시한다.

- 12개 장소의 부지 범위·이름·주요 건물 크기 검토 상자.
- 도로 후보와 건물을 피한 진입선. 경사 검토가 남은 도로는 주황색.
- 왼쪽 아래 장소 선택으로 가까이 이동, 전체 배치/표시 숨기기 가능.
- 도로 표시선은 지면 위에 띄운 검토용 선이다. 다리 상판을 그대로 재현한 도로 메시가 아니다.
- 상자 치수는 설계 검토용 초안으로 기존 모델 완성도나 실내/충돌 완성을 의미하지 않는다.
- scene에 독립적으로 넣으며 게임 충돌체를 만드는 world.group에는 추가하지 않는다. story/play 모드와 동시에 표시하지 않는다.
- 검토 화면에서는 안개를 제거하고 기존 메뉴를 접어 전체 배치를 읽기 쉽게 했다.

검증: TypeScript 검사 및 Ogimachi 빌드 통과. 브라우저에서 실제 지도 로딩·검토 UI·전체 배치 표시 확인.
