# 선택 범위 내 스토리 장소 배치 초안

사용자가 그린 넓은 유지 범위를 기준으로 12개 지상 구역 좌표를 잡았다. 기존 초반 동선을 유지하기 위해 중앙 신사를 입구 북쪽에 두었다. 원본 마을의 실제 시설 이름과 게임 내 역할은 서로 다르다.

실행 화면: `/docs/ogimachi-reconstruction/story-layout.html`
좌표 및 건물 분류: `public/data/ogimachi/story-layout.json`
재생성: `node --import ./tests/register.mjs scripts/ogimachi/plan-story-layout.mjs`

- 중앙: 기존 도입부 → 광장 → 신사, 서측 공동우물.
- 북서: 폐교 대형 부지 → 묘지 → 산중 사당.
- 북동: 촌장 저택 기존 부지.
- 남측: 할머니 집·여관·논길, 남서쪽 최종 탈출 구간.
- 신사 지하·우물 내부는 별도 높이/공간으로 제작. 버스 실내·회상·에필로그는 별도 세트 또는 같은 장소 상태 전환.
- 노란 점선은 연결 의도이며 도로/충돌을 따라 검증한 보행 경로가 아니다. 특히 최종 탈출 연결은 이후 지형에 맞게 세분화해야 한다.
- 기존 부지 활용 후보 4동, 장소 주변 우선 제작 후보 43동. 배경 분류 409동에는 게임 로딩에서 제외된 3동도 포함한다. 분류는 원본 전체 456동 기준이며 추가 삭제를 뜻하지 않는다.
- 12개 중심점은 모두 사용자가 선택한 유지 영역 안에 들어오는지 검사했다. 원의 전체 면적/지형 경사/다른 건물과 충돌은 아직 검증하지 않았다.
- 현재 실제 플레이 연결은 ACT 1–3만 유지한다. 이 배치도를 제작 완료 또는 액트 연결 완료로 간주하지 않는다.

## 다음 제작 순서

1. 광장·신사 부지의 실제 점유 건물과 경사를 확인하고 회색 블록으로 통행 폭 확보.
2. 신사에서 학교·우물·묘지·여관·저택까지 기존 길을 따라 왕복과 우회로 확정.
3. 검증된 길에서 보이는 건물만 우선 제작 후보에 추가. 주변 43동은 아직 확정 수량이 아님.
4. 핵심 장소부터 외형/실내/충돌/액트 연결을 함께 완성.
