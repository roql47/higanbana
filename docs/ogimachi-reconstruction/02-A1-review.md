# A1 첫 대조 기록

2026-09-11. 대상 묶음: 236248652, 236248688, 236248633. 이번 기록은 첫 건물 236248652의 기준 사진과 비교 카메라 준비까지다. 묶음 전체 외관 검수 완료가 아니다.

## 기준 사진

[2012년 9월 서쪽 정면](https://www.google.com/maps/@?api=1&map_action=pano&viewpoint=36.25997,136.90697&heading=270&pitch=8&fov=100)을 다시 열어 촬영 월과 pano tcA1tFv0uHCgiNklZQAEjw를 확인했다. 실제 선택된 좌표는 36.2599765,136.9069649, 방위 270°, 위쪽 기울기 8°. 주소의 90y를 수평 시야각 90°로 해석한 비교 화면이며 촬영 높이는 미제공이라 2.5m를 잠정 사용한다. 픽셀 정합이 완료된 카메라가 아니다.

## 확인한 차이와 검수 과제

- 사진: 전면의 위층 덩어리와 처마에 높이 차이가 있고, 창문과 출입구 배치가 비대칭이다.
- 현재 제작 코드: 단일 직육면체와 한 높이의 주 지붕, 등간격으로 배치한 전면 창문을 사용한다. 외형 교정 대상이다.
- 사진의 지붕 분절이 인접 필지까지 포함하는지 확인해야 한다. 한 필지의 모델을 임의로 늘리지 않는다.
- 사진상 유리 반사·커튼·현관 차양/노렌·설비는 현재 단순화되어 있다. 큰 형태 확인 후 세부 단계에서 처리한다.
- 첫 비교 화면에서 카메라가 의도한 높이보다 올라가는 문제가 있었다. OrbitControls의 maxPolarAngle이 수평 위쪽 시선을 금지했기 때문이다. 원본 대조 A1 버튼에서 위쪽 시선을 허용하도록 수정했다.

## 다음 순서

1. 카메라 높이와 시야각을 사진상 수직선/처마로 보정한다.
2. 236248652와 남쪽 인접 필지의 관계를 지도와 다른 방향 사진으로 교차 확인한다.
3. 236248688·236248633의 개별 기준 사진도 같은 방식으로 확정한다.
4. 확정된 필지 안에서 지붕 분절과 개구부 차이를 교정한 뒤 전후 화면과 검수 결과를 기록한다.

현재 상태: 기준 사진 재확인, 대조 시점 추가, 비교 도구 오류 수정. 건물 형태 수정과 A1 검수 통과는 아직 아니다.

화면 검수: 같은 서쪽 방향에서 남쪽 높음·북쪽 낮음의 순서를 확인했다. 남쪽 작은 창의 좌우가 반대여서 화면 왼쪽으로 옮기고 셔터는 오른쪽으로 보정했다. 지붕축 차이는 아직 미해결이다. 건물 폭·촬영 거리·지면 높이의 정밀 일치도 미검증이다.

## 지붕 교정 — 후속 작업

- 236248633: 지도 회전각 약 92° 때문에 기존 지붕의 용마루가 동서로 놓여 도로 쪽에 박공이 보였다. 2010년 사진은 낮은 지붕의 처마와 경사면을 보여준다. 지붕·박공만 내부에서 90° 회전하고, 벽체·필지 배치·문 위치는 보존했다.
- 236248652: 남쪽 사선 사진을 추가 확인했다. 실제 pano vhHbwNydXKsUDvAlKpkVyw, 2010년 8월, 좌표 36.2599095,136.9069451, 방위 295°, 기울기 8°. 2012년 정면 사진에서도 보인 북쪽 높은 전면과 남쪽 낮고 뒤로 들어간 형태가 재확인된다. 기존 단일 지붕을 기존 필지 안의 북/남 두 덩어리로 나누고 위층 창 배치를 조정했다.
- 남쪽 비율 40%, 후퇴 0.85m, 처마 높이 5.25m/5.92m 등은 사진 기반 추정값이다. 건축상의 동일 동 여부나 실측 경계를 확정한 것은 아니며 필지를 확장하지 않았다.
- 남쪽 주변 격자·벤치와 세부 재질은 후속 세부 검수 대상이다. 기준 사진의 촬영 높이/시야각 정합과 재질 차이는 남아 있으므로 A1 완전 일치 판정은 보류한다.

남쪽 격자와 벤치 위치도 벽 후퇴량 0.85m만큼 함께 이동했다. 모델 관련 검사 5개와 Ogimachi 빌드 통과. 같은 시점의 화면 크기/높이 보정과 실측 검증은 여전히 미완료다.

## 정면 겹침 교정

첫 상가의 기존 북쪽 창 범위는 로컬 y=1.103~6.461m였고, 격자 패널 범위는 2.006~3.036m여서 완전히 겹쳤다. 기존 출입구 범위 -2.127~-0.079m는 남북 벽 단차 경계 -1.576m를 가로질렀다. 출입구를 남쪽 벽 안으로 옮기고 북쪽 창 두 개와 양끝 격자를 서로 분리했다. 이는 기하학적 겹침 제거이며 사진의 정확한 창 치수 검증과는 다르다.

카메라 90°를 수평 시야각으로 해석한 비교는 아직 잠정이다. 원본 화면보다 모델이 크게 보이는 이유를 모델 폭 오류로 단정하지 않는다. 촬영 시야각/위치 오차를 분리하기 전 지도 필지 크기를 축소하지 않는다.

## 비교 카메라 기준 통일

Google Maps URLs 공식 문서 https://developers.google.com/maps/documentation/urls/get-started#street-view-action 를 확인했다. fov는 수평 각도이며, viewpoint만 지정하면 다른 촬영본으로 이동할 수 있다. 기존 사진 요청 fov=100과 모델의 90° 설정이 달랐다. 이제 기준 데이터에서 사진 링크와 모델이 같은 100°를 사용하고, 파노라마 ID를 고정한다. 앞 기록의 URL 내부 90y를 근거로 90°를 확정한 해석은 철회한다. Google UI가 실제로 요청값을 그대로 표현하는지까지 픽셀 검증한 것은 아니다.

창 크기가 바뀌어도 수평 시야각을 유지하도록 세로 시야각을 재계산한다. 대조 시점으로 이동할 때 기존 드래그 관성도 비운다. 미리보기에서 기준 사진의 날짜·시야각과 직접 여는 링크를 제공한다. 포트레이트/정방형/와이드 화면의 수평 투영 경계 및 사진 ID 고정 검사가 통과했다.

100° 보정은 기존 90°보다 같은 물체의 화면 폭을 약 16% 줄인다(1/tan(50°)). 이 차이만으로 원본과 모든 비례가 일치한다고 판단하지 않는다. 촬영 높이 2.5m는 여전히 추정이며 사진 좌표 정확도와 지면 높이 검증이 남아 있다.

## 위층 창 비례·구성 교정

고정된 2012년 사진을 다시 보며 첫 북쪽 위층 창의 유리 영역을 화면상 대략 x=221~352, y=271~340으로 읽었다(573×803 화면, 수동 판독). 약 1.9:1이며 원근 왜곡과 수동 판독 오차가 있다. 기존 모델은 폭 3.624m/높이 1.6m로 약 2.27:1이었다. 화면 전체 배율과 별개인 국소 비례 차이로 판단해 북쪽 첫 창을 폭 2.994m/높이 1.6m, 약 1.87:1로 조정했다. 다른 위층 창도 사진을 참고한 비례로 조정하되 실측 일치로 표시하지 않는다.

위층 창에 네 칸 분할, 창틀 뒤쪽 린넨 커튼과 세로 주름, 돌출 창턱을 추가했다. 사진 픽셀을 재질로 사용하지 않았다. 전체 카메라 정합은 미완료로 유지하며, 확인 가능한 국소 비례·세부 요소부터 교정한다. 전면 창/처마 기준점을 모두 맞춘 최적화나 실측 복원은 아니다.

## 처마·아래층 출입구 교정

2010년 사선 사진과 2012년 정면 사진에서 확인한 처마 아래 사선 지지대·서까래와 전면 테두리를 반영했다. 지지대는 벽과 처마 사이에 두며 별도의 길 위 기둥을 추가하지 않았다. 정확한 부재 단면·간격은 추정이다.

남쪽 출입구와 북쪽 좁은 출입구는 기존의 창문 형태 대신 바닥 쪽까지 내려오는 미닫이문으로 분리했다. 문틀·세로살·하부 목판·손잡이·문턱을 추가했다. 다른 아래층 창에도 추가 세로살을 넣었다. 문이 실제로 열리거나 실내로 들어가는 기능을 추가한 것은 아니다.

2012년 정면 사진의 보라색 가림천을 다섯 장의 단색 패널과 봉으로 표현했다. 원본의 글자는 판독/복제하지 않았다. 가림천 수와 치수·정확한 문짝 구획은 추정이며 현재 시점 영업 상태를 뜻하지 않는다.
