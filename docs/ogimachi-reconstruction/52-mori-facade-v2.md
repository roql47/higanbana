# B003 숲의 전승관 외관 보강

기존 2010년 정면 관찰 기록과 제작 스크립트를 재사용해 별도 Blender 장면을 제작했다. 새 사진 정합이나 현재 외관의 실측 복원으로 주장하지 않는다.

추가: 상층 창턱·측면 창틀 깊이·빗물 흘림 금속판, 하층 창턱, 처마 마감판·홈통 지지대. 목재·창틀 모서리는 3.5mm 베벨, 커튼은 2mm 두께를 적용했다. 기존 목재·석재 PBR, 창문 배열, 분홍 커튼, 바구니 진열대와 화분을 재사용했다. 후면은 기존 추정 단순 외벽이며 실내 플레이는 미구현이다.

- 편집본: `assets/authored/ogimachi/B003-mori-v2.blend`
- 제작: `scripts/blender/refine-mori-v2.py`
- 렌더: `artifacts/ogimachi-phases/mori-v2/facade.png`
- 게임 모델: `public/models/ogimachi/mori-workshop-v2.glb` (3,811,536 bytes, 메시 13개, 텍스처 4개)
- 보기: `/ogimachi.html?view=detail&building=mori`

Blender 렌더를 열어 형태와 재질을 확인했고 게임 배치·크기는 기존 측량값을 유지한다. 간판 글자는 기존 게임의 별도 레이어를 사용하므로 Blender 렌더에는 빈 나무판으로 보인다.
