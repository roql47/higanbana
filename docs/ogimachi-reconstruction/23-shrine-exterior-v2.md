# 신사 외형 2차

검토: `/ogimachi.html?view=detail&layout=1&site=shrine&clean=1`

Blender 모델을 갱신했다. 밝은 판재 벽, 툇마루 판재, 측면/전면 난간, 서까래, 처마 끝판, 출입문 테두리·손잡이, 디딤돌을 추가했다. 4단 계단은 기단 상면 0.5m부터 마루 상면 1.25m까지 단차 0.1875m로 수정했다.

지붕의 누락된 UV를 추가하고 목재·지붕에 노멀/거칠기 맵을 연결했다. 모든 재질을 밝게 바꾼 것은 아니며 구조 목재와 지붕은 어두운 재질을 유지한다.

GLB 1,820,384 bytes, 8개 메시 그룹. Blender 원본도 갱신했다. GLB UV/노멀/거칠기 연결 검사, TypeScript 검사, Ogimachi 빌드 통과. 실제 브라우저에서 외형과 난간 표시 확인.

여전히 검토 화면 전용. 실내·지하·상호작용·충돌 미적용. 넓은 기단의 지형 접합과 마당 재질, 곡선 지붕·세부 장식은 후속 작업이다.
