# A1 창고 두 동 — 재질과 셔터 디테일

2026-09-11. 가까운 가게에 이어 236248688·236248633의 표면을 보완했다.

- 황토색 벽에 미세 요철·색 변화·약한 세로 얼룩을 가진 전용 PBR 재질을 적용했다.
- 금속 지붕과 셔터에 색상·노멀·거칠기 맵을 추가했다. 금속성은 0.25로 두어 칠해진 표면을 과도한 거울처럼 만들지 않았다.

재질은 사진에서 채취한 스캔이 아닌 전용 절차 생성 재질이다. 세부 치수와 노후 얼룩 위치는 추정이다. 기존 위치·높이·개구부 배치는 유지했다. 공용 황토색 재질을 사용하는 A2 벽도 재질을 공유하지만, A2 전체 디테일 완성을 의미하지 않는다.
