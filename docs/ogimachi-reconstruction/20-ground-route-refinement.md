# 도로 표면 기준 경사 재검사와 부지 조정

- 원본 DEM만 검사하던 방식에서 실제 SurveyWorld의 지면 높이 계산과 roadStrip 도로/다리 삼각형을 재사용하는 방식으로 변경했다.
- 우물 중심 후보를 (-165,-55)에서 (-86,-87)로 이동. 약 85m 위치 조정으로 접근선 103.2m → 12.8m.
- 논길 중심 후보는 (-320,85)에서 (-231.1,225.3) 농지 인근으로 이동. 접근선 69.4m → 57.5m. 할머니 집 방면 도로 연결은 839.5m → 33.2m. 부지 양쪽 진입 거리는 별도다.
- 최종 탈출 도로는 표면 계산상 최대 경사 약 21.6%. 실제 캐릭터 통행 확정은 아니다.
- 남은 경사 검토 연결 5개: 신사–저택, 저택–학교, 학교–광장, 신사–묘지, 논길–학교. 여러 연결이 같은 급경사 구간을 공유할 수 있다.
- 새로운 계산으로 건물 부지 평탄화 영향도 반영되어, 원본 DEM만으로는 놓쳤던 학교 쪽 경사가 검출됐다. 이전 6개와 현재 5개는 같은 기준의 단순 개선 수치가 아니다.
- 지도에서는 새로운 도로 표면 경사를 기준으로 주황색 경고를 표시한다.

## 검증과 한계

검사 7개: 장애물 우회/범위/외곽 접근점 5개, 다리 아래 계곡과 상판 높이 구별 및 일반 도로 경사 2개.
실제 데이터: 12개 접근선 건물 교차 0, 15개 연결 유지, 우물 접근 15m 미만, 경사 검토 연결 5개 확인.

아직 배치·경로 설계 단계다. 게임 지형·건물 모델은 수정하지 않았으며, ACT 1 별도 덧씌움/교차 도로 접합 높이/실제 충돌/캐릭터 보행은 별도 검증이 필요하다.
