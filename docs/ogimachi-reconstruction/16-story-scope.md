# 사용자 선택 범위 적용

- 사용자 직접 그린 유지 영역 2개를 `public/data/ogimachi/story-selection.json`에 저장.
- 두 영역의 합집합을 사용. 자기 교차는 선택 도구와 런타임 모두 even-odd 판정.
- 경계 30m 여유 + 건물 반경으로 경계 건물이 잘리지 않게 보존.
- SurveyWorld 기본 로딩에 적용. 원본 survey와 Blender 파일은 변경하지 않음.
- 건물 456 → 453, 논밭 101 → 101. 범위가 마을 대부분을 포함하므로 건물 감축은 작음.
- 외곽 일반 도로는 5m 이하 간격으로 분할해 범위 밖 제외.
- ACT 1–3이 사용하는 도로 1268046903은 경로 거리/시작 인덱스 보존을 위해 전체 유지.
- DEM, 항공사진 지면, 산과 숲은 배경으로 그대로 유지. 지형 자체 절단과 이동 경계 차단은 미적용.
- `?view=detail&scope=original`로 원본 범위 비교 가능.
- 전체 액트 목적지 배치와 정밀/배경 건물 분류는 후속 작업.

검증: TypeScript 검사 통과, Ogimachi 빌드 통과. 실제 데이터 필터 및 도로 원본 유지, 좌표 유한성, 영역 내부/외부/여유/제외 영역 판정 확인.
