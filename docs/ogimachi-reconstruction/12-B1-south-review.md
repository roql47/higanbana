# B1 추가 — 초가 가게의 남쪽 면

2026-09-11. B5에서 확보한 [2010년 8월 남쪽 사진](https://www.google.com/maps/@?api=1&map_action=pano&pano=5EAynUU1NHuh27_aYEPczg&heading=70&pitch=5&fov=100)으로 236248636의 남쪽 면을 추가 교정했다. 기존 B1 기록은 북쪽 면만 다뤘다.

## Blender 적용

- 남쪽 다락의 단일 창을 두 창으로 분리했다.
- 아래층의 반복 주택 창을 가게의 긴 미닫이 유리 패널과 문틀·가로대로 바꿨다.
- 서쪽 차양에서 남쪽 모서리로 이어지는 차양, 기둥과 버팀대를 추가했다.
- 정면의 낮은 벤치와 출입구 문턱을 추가했다. 정확한 수량·치수·출입구 폭은 사진 기반 추정이다.

사진의 간판 글자·붙임 종이·상품·화분은 이번 수정에 포함하지 않았다. 창의 유리/격자 비율, 처마 연결부와 목재 질감은 추가 검수 대상이다. 기존 필지와 높이를 유지했으며 보이지 않는 동쪽 면은 여전히 추정 표현이다.

기존 교정 건물의 다른 면을 보완한 작업이므로 35동 중 9동, B 묶음 4/9동이라는 집계는 유지한다. 미리보기에서는 기존 원본 대조 B5를 사용한다.

검증: 모델 관련 검사 5개와 ogimachi 빌드 통과. B5 화면에서 다락창 두 칸, 남쪽 미닫이 정면, 이어지는 차양과 벤치를 확인했다. 정면 유리가 원본보다 균일하게 보이고 목재 노후감·가게 소품이 부족하므로 세부 검수 완료로 표시하지 않는다.
