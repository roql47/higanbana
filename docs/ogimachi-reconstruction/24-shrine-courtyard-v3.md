# 신사 마당 3차

Blender 모델의 회색 기단 상판을 기존 packed-gravel 텍스처 기반 흙·잔자갈 마당으로 변경했다. 3m 단위 UV, 가장자리 두 단 석축, 도리이 앞 진입 계단을 추가했다. GLB 2,691,024 bytes, 10개 재질별 메시 그룹.

검토 모드에서만 신사 부지 지면을 평탄화하고 경계 바깥 4m 구간을 원래 지형으로 보간한다. 실제 스토리/자유 이동에는 적용하지 않는다. 경계는 기존 지형 메시 해상도 때문에 일부 각이 남으며, 자연스러운 흙 비탈과 식생 마감은 후속 작업이다.

검증: 평탄화/외부 보존/경계 연속성 및 기존 도로 표면 검사 5개 통과. TypeScript 검사·Ogimachi 빌드 통과. 브라우저에서 흙마당·석축·입구 표시 확인.

실내·지하·플레이 충돌·ACT 연결은 아직 미완료.
