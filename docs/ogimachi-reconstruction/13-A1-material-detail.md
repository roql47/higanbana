# A1 가까운 가게 — 재질과 입체 디테일

2026-09-11. 사용자가 기존 결과의 완성도가 부족하다고 지적해, 건물 수 확대를 멈추고 236248652의 가까운 정면에 집중했다.

## 실제 적용

- 단색 석회벽·구조 목재·기와를 전용 색상/노멀/거칠기 맵으로 교체했다. 새 맵은 결정적인 절차로 생성한 512px 반복 재질이며 원본 사진을 복사한 텍스처가 아니다.
- 목재 결 UV를 부재 길이 방향에 맞추고 두꺼운 목재 모서리에 작은 bevel을 적용했다.
- 위층 창에 깊이 있는 문설주·상부 틀, 처마 아래 반복 서까래를 추가했다.
- 도로 쪽 지붕에 개별 곡면 기와 조각을 추가했다.
- 아래층 창의 블라인드/커튼을 구분하고, 가게 앞 천은 평판에서 굽은 주름 면으로 변경했다.
- 원본 `.blend`와 게임 GLB를 함께 갱신했다. 모델이 공유하는 A구역 재질도 함께 갱신됐지만, 다른 건물 전체의 재질 작업이 완료된 것은 아니다.

생성기: `scripts/blender/act1-materials.py`, `scripts/blender/build-ogimachi-act1.py`. 새 재질 파일: `public/textures/ogimachi/frontage/`. 게임용 GLB는 WebP로 압축한다.

## 검증과 남은 한계

GLB에서 벽·목재·기와의 색상/노멀/거칠기 텍스처가 실제 연결된 것을 확인했다. 모델 검사 5개와 ogimachi 빌드 통과. Blender 스크립트 구문 확인 통과.

이 작업은 원본과의 실측 비례 일치를 증명하지 않는다. 상점의 내부·상품, 정확한 창문 반사와 노후 흔적, 주변 조명·지형과의 최종 조화는 남아 있다. 건물 수는 9/35 그대로이며 이를 완성률로 쓰지 않는다.
