# 페이즈 2 도로 경계 교정

항공사진에 저장된 도로 좌표를 주황색으로 중첩했다. 중심 보행로 540155249는 사진에서 보이는 곡선 길과 대체로 대응한다. photo-north-0, 2, 6, 7의 추정 논 윤곽이 이 길을 가로지른다. 7번은 34320767 및 236248800 갈림길도 포함한다.

0, 2, 6번을 사진에서 길 동쪽으로 구분되는 일부 경작 영역으로 보수적으로 다시 그렸다. 이는 전체 논의 정확한 복원이 아니라 확인 가능한 부분의 초안이다. 7번은 경계 미확정으로 수면 생성을 보류한다. 건물이나 도로 자체를 옮기지 않았다. 수정 데이터는 artifacts/ogimachi-phases/parcel-overrides.json에 별도 저장하며 게임 survey.json은 그대로다.

Blender MCP로 논 9구획 재생성, phase2-paddies.blend 저장, 렌더 직접 검수. 모든 지도 보조선은 렌더에서 숨기고 Blender 편집용으로 보존해 실제 논둑과 구분했다. 도로 포장 메시는 아직 제작하지 않았다.

검사: 현재 9구획 모두 저장된 건물 윤곽과 도로 중심선의 내부 교차 없음. 도로 폭, 길어깨 및 둑 폭 여유를 인증하는 검사는 아니다. 교차점 대장: road-parcel-intersections.json. 원본 구도 일치 검수 및 게임 반영은 미완료.

재생성 순서: review-phase2-parcels.py → review-phase2-roads.py → Blender build-ogimachi-phase2-paddies.py. 첫 감사 스크립트는 이제 이미 저장된 후속 교정을 덮어쓰지 않는다.

다음: 보류한 7번 및 길어깨 폭 확인, 첫 건물의 참조 사진을 확정하고 지붕·외벽 제작. 테스트용 단순 건물은 완성 가옥으로 계산하지 않는다.
