# Sign revision 7

Reference: official Irori entrance photo embedded in photoreal-compare.html, inspected enlarged in the browser. The reference uses broad irregular strokes arranged diagonally downward to the right. The prior generic handwritten interpretation incorrectly used horizontal placement and extended above the irregular slab.

Removed V2 shop crest at user request. Replaced all previous lettering with five mesh stroke outlines manually traced from the enlarged reference image. The photograph is perspective-distorted and low resolution, so this is an approximate outline reconstruction, not exact calligraphic reproduction. Paint remains on the existing wood material.

All outline vertices were ray-tested against the actual sign silhouette, including four 3 cm offset samples. A Blender render was visually inspected for edge containment and absence of the crest. Comparison pages now use sign-v7-final.png. Runtime is regenerated through the existing v5-named bake/optimization pipeline.
