# 사당·폐교 플레이 연결 1차

- siteplay=school / siteplay=hokora에서 원본 건물과 소품을 실제 Rapier 월드에 생성한다.
- 폐교 자리의 기존 외피 건물을 제외해 내부를 막는 중복 충돌을 방지한다.
- 출입 버튼으로 실내/외를 이동하고, 실내에서 WASD와 근접 E 조사를 사용한다.
- 학교 신발장·교무일지·출석부·방송실·빗, 사당 제단·아이 흔적에 조사 지점을 연결했다.
- 학교 상세 소품 로드를 기다린 뒤 플레이를 시작한다.
- 브라우저에서 학교 내부 진입과 신발장 조사 메시지 확인.
- 브라우저에서 사당 내부 진입 확인. 야외 징검돌과 소품은 건물 기준면 대신 실제 지형 높이를 사용한다.
- 시작점 복귀 시 출입 버튼 상태도 초기화한다.

폐교 입구 보정: 주변 최고점으로 건물을 띄우던 처리를 제거하고, 입구 높이에 맞춰 실제 지형을 평탄화했다. 건물과 현관 주변은 같은 높이를 사용하고 외곽 8m에서 기존 경사로 연결한다. 렌더 지형에서 충돌면을 생성하므로 두 표면에 같은 보정이 적용된다. 현관 계단의 폭 방향과 충돌체도 입구 방향에 맞췄다.

현재는 출입 및 조사 위치 확인용이다. 문턱을 연속 보행하는 출입 검증, 전체 액트의 대사·적 등장·아이템 획득·저장, 사당 주변 지형과 건물 기초의 정식 정지는 아직 남았다. 새 조사 문구는 위치 확인용이며 원본 액트 완료로 저장하지 않는다.
