# 원본 우물 재사용

- 배치 확인 화면과 well=1 플레이 화면 모두 새로 만든 story-well 대신 기존 Well과 /models/props/well.glb를 사용한다.
- 기존 맵 생성자의 기본 좌표는 유지하고, 새 맵에서는 지정된 우물 좌표를 전달한다.
- 원본 충돌 크기를 재사용하며 기존에 이식한 WellShaft 지하 공간과 하강/귀환 연결을 유지한다.
- 원본 모델 로드를 기다린 후 플레이를 시작한다. 모델 실패 시 기존 원본 코드의 절차형 대체물이 남는다.
- 타입 검사, 배포 빌드, 30/60/120 FPS 우물 충돌 테스트 통과.
- 전체 ACT10 연출 및 저장 시스템 연결은 별도 남은 작업이다.
