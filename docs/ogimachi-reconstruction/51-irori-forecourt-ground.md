# 이로리 정문 소품 지면 보정

석등 바닥은 모델 원점보다 2cm 위에 있지만, 기존 2m 부지 가장자리 보간과 4m 지형 격자로 인해 실제 지면이 소품 기준면을 넘을 수 있었다. 식당 정면(-X)에 평탄한 마당 범위를 확장하고 바깥 4m에서 경사를 연결했다. 조회용 공간 격자의 검색 반경도 확장했다. 건물 전체나 소품을 위로 이동하지 않는다.

같은 지형 메시로 보행 충돌을 생성한다. 이웃 건물의 실제 발자국 높이는 기존 우선순위를 유지한다. 회전된 부지의 소품 위치, 보정 범위 밖 지형, 이웃 건물 우선순위 테스트와 타입 검사·빌드를 통과했다. 브라우저 정문 시점에서 석등·화분·좌측 소품의 하단을 확인했다. 모든 측면에 대한 전수 검수는 아니다.
