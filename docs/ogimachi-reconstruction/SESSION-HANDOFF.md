# 오기마치 공간 제작 · 상세 모델링 인계

갱신: 2026-09-13. 최신 방향은 **기존 배치를 유지하고 실제 배경 이미지를 먼저 맞춘 뒤 건물·에셋을 자연스럽게 통합**하는 것이다. 상세 모델링은 다른 세션에서 진행한다. 아래 이전 공간 제작 계획보다 최신 방향을 우선한다.

## 최신 추가 · 폐교 작업 재개

사용자가 다음 건물 제작을 명시적으로 요청하여 폐교 공간 구성을 재개했다. [57-school-site.md](57-school-site.md): 기존 학교 재사용, 서쪽 입구 울타리·표지·스폰 및 조사 7곳. 빌드/타입 검사와 외부·실내 진입 확인. 도로 연결 재계산·보행 검수·성능 개선은 남아 있다. 실제 배경 합성은 완료되지 않았으며 기존 사진 비교 기능을 유지한다.

## 최신 방향 · 기존 배치 유지, 실제 배경 우선

사용자는 실제 레퍼런스 배경 이미지를 먼저 사용하고 기존 건물·에셋을 나중에 자연스럽게 추가하는 방향을 지정했다. 이어서 “그냥 두고 이어서 진행해”라고 했으므로 현재 사당과 기존 모델은 삭제하거나 숨기지 않았다. 기존 공간 제작 순서는 배경 작업 이후의 후보로 남긴다.

`preview.ts`의 **실제 배경 맞추기**에서 로컬 PNG/JPG/WebP를 선택하거나 붙여넣고 농도를 조절해 기존 3D 맵과 구도를 비교할 수 있다. `photoReference.ts`는 화면 위 정지 사진 비교 기능이며, 지형 텍스처·3D 투영·플레이용 배경 구현이 아니다. 사진은 탭 안에서만 유지되고 새로고침하면 해제된다. 기존 지도·충돌·모델 파일은 변경하지 않는다.

현재 확인된 로컬 실사 자료는 항공사진(`public/data/ogimachi/orthophoto.webp`)이다. 지상 사진은 `referenceCamera.ts`에 거리뷰 참조 링크가 있으나 배경으로 확정한 원본 이미지 파일은 아직 없다. 다음 단계는 사용할 지상 사진과 촬영 시점을 확정하고, 이동 범위를 고려해 배경 배치 방식을 결정하는 것이다. 배경 합성 완료로 기록하지 않는다.

## 4. 모델을 바꿀 때 보존할 계약

### 전승관 외관

- 필지 ID `236248644`, 모델 식별자 `mori-workshop`, 정면 로컬 `+X`.
- 기준 외곽 크기 `[11.42, 14.274]`. 배치·회전·높이는 `surveyWorld.ts`의 현재 로더 기준을 따른다.

### 전승관 실내

- 실제 내부 복원이 아닌 **스토리용 창작 공간**. 외관과 별도 모델이다.
- Blender는 Z 위, 게임은 Y 위다. Blender Y 증가가 게임 로컬 -Z 방향으로 변환된다.
- 게임 실내 원점 `(0, 800, 0)`, 바닥 로컬 Y=0. 현관 스폰 `(0, 800.03, 4.25)`.
- TV는 실내 오른쪽 안쪽. 게임 화면 면 중심 `(2.8, 801.25, -3.473)` 부근. TV나 책상을 움직이면 화면·조사 지점·TV 카메라도 함께 수정한다.
- 중앙 통로와 관리 공간 진입로를 보존한다. 의자는 TV 정면을 막지 않도록 옆으로 이동한 상태다.
- 충돌용 빈 오브젝트의 `collisionBox`는 **게임 축 순서 [너비, 높이, 깊이]**. 현재 16개. 최적화의 `prune({keepExtras:true})`를 유지해야 사라지지 않는다.
- 현재 출입은 240ms 암전 후 별도 공간 이동. 내부 1인칭, 외부 복귀 3인칭. 하나의 연속된 내부 메시로 연결한 상태가 아니다.

### 중앙 신사

- 월드 기준 위치 `(-90, base, -260)`. base는 현재 높이 함수에서 계산한다.
- 경내 바닥은 모델 원점보다 0.5m 높고, 디딤돌·계단은 별도 높이를 가진다. 캐릭터를 지형 높이에 강제로 맞추지 않는다.
- 평탄화 함수 `shrineSite.ts`: 중심 약 `(-90,-262)`, 반폭 11.65m/반깊이 14.15m, 바깥 4m 완화 구간.

- 기존 모델에 받침대가 이미 일곱 개 있다. 새로 일곱 개를 추가하지 않는다.

| 3 | 신사 귀환·첫 봉납 ACT 7 | 방울 소지 확인 → 해당 자리 봉납 → 한 번만 소비/변화, 다음 목적지 안내 |
| 4 | 폐교 ACT 8–9 | 진입 높이·교실/복도·책상·기록 위치 확정 후 조사·추격 동선 연결 |
| 5 | 공동우물 ACT 10–11 | 경계 지형·우물 높이·하강/복귀 공간과 필수 소품·상호작용 연결 |
| 6 | 이후 장소 | 묘지·여관·저택을 스토리 순서에 따라 같은 절차로 진행 |

검증이 안 된 길을 ‘완성된 동선’으로 표시하지 않는다. 다음 장소를 늘리기 전에 직전 장소의 입구·바닥·필수 조사 지점이 사용 가능한지 확인한다.
