# ACT 5 · 중앙 신사의 거짓된 탈출법

2026-09-13. 전승관 ACT 4 다음 단계를 연결했다. 54번 문서의 ‘석판 연결 전’ 상태를 갱신한다.

## 구현

- 기존 `story-shrine.glb`를 플레이에서도 불러오고, 모델 메시를 지형과 별개로 실제 충돌면에 등록했다.
- 검토 화면에만 있던 신사 경내 평탄화를 스토리 및 전승관/신사 플레이에도 적용했다. 미오의 정지 접지는 신사 바닥과 디딤돌 충돌면을 따른다.
- 기존 일곱 받침대를 재사용한다. 중앙 받침대와 쟁반의 폭만 늘리고 맨발 두 짝의 흔적을 추가했다. 다른 여섯 자리에는 둥근 마모를 표시했다.
- 석판, 넓은 받침대, 안에서 잠긴 본전 문을 가까이서 E 또는 버튼으로 조사한다.
- ACT 4의 서로 다른 흔적 세 곳이 석판 진행 조건이다. 전승관 TV를 다시 조사해 조건을 우회할 수 없다.
- 기존 ACT 5의 일곱 대사를 순서대로 읽은 뒤 마지막 입력으로 공물 목표를 시작한다. 중간에 떠나거나 석판에 접근한 것만으로 목표가 열리지 않는다.
- 목표 시작 뒤 `일곱 공물을 찾아라 0/7`과 첫 목적지인 작은 사당을 안내한다. 석판을 다시 읽어도 진행도를 초기화하지 않는다.

## 검증과 경계

- 상태 검사 5건: 증거 부족, 중복 조사, 대사 중단, 끝까지 읽기, 재조사.
- 실제 내보낸 신사 모델을 Rapier에 넣어 입구→넓은 받침대 우회→석판→복귀와 바닥 접지를 검증했다 (`scripts/qa/check-shrine-courtyard.mjs`).
- 게임에서 신사·석판을 확인하고 순차 대사 후 공물 목표로 바뀌는 UI를 확인했다. 이 순차 대사 검수는 개발 전용 `moriInspect=shrine`에서 흔적 세 개를 준비한 상태로 수행했다. ACT 1부터 이곳까지의 전체 실시간 완주 검증은 아니다.
- 타입 검사 통과. 최초 전체 빌드는 다른 작업의 `irori-restaurant-interior-v4.glb` 파일 부재로 자산 복사에서 실패했다. 신사 관련 검사는 통과했다.
- 이번 범위는 ACT 5와 공물 목표 시작이다. ACT 6의 방울 획득, 귀환 후 봉납, 봉인 변화는 아직 연결하지 않았다. 진행 저장/불러오기도 후속 작업이다.
