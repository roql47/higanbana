# A1 지면·거리 수치 점검

현재 지도와 실제 런타임 높이 함수를 사용한 결과다. 원본 사진에서 실측한 값이 아니다.

| 대조 대상 | 촬영점 지면−건물 바닥 | 지도 외곽까지 최단 거리 | 가정한 카메라 높이 |
| --- | --- | --- | --- |
| 첫 상가 236248652 | +0.452m | 6.702m | 촬영점 지면+2.5m |
| 남쪽 창고 236248688 | +0.855m | 18.665m | 촬영점 지면+2.5m |
| 북쪽 창고 236248633 | +0.925m | 18.902m | 촬영점 지면+2.5m |

첫 상가 카메라의 건물 바닥 기준 높이는 2.952m이다. 이전 카메라의 위쪽 시선 제한 문제와 달리, 이 수치만으로 지형 오류를 확정할 수 없다. 원본 촬영 높이와 위치 오차는 미확정이다. 따라서 이번에는 건물이나 지형을 억지로 이동시키지 않았다.

재현: `node --import ./tests/register.mjs scripts/qa/audit-act1-reference.mjs`. 수치 원본: 03-camera-audit.json. 향후 지형 변경 시 재실행해 비교한다.

미리보기의 큰 메뉴가 정면 상부를 가려 육안 검수에 지장을 주므로 메뉴 숨기기/보기를 추가했다. 원본과 같은 화면 비율로 비교하고, 좌우 외곽·처마·창턱·바닥선을 각각 확인한다. 촬영 높이만 바꿔 억지로 맞춘 결과는 외형 검수 통과로 취급하지 않는다.

판정: 수치 기준 확보. 원본과 픽셀 정합은 아직 미완료. A1 외형 변경은 현 상태를 유지하고 추정값을 실측값으로 올리지 않는다.

고정 파노라마를 세로 화면으로 다시 열어 확인한 결과, Google UI는 건물 오른쪽을 잘라 보이는 반면 모델의 수평 100° 고정 화면은 정면 전체를 담았다. 따라서 URL 요청값을 통일한 것과 실제 표시된 투영이 일치하는 것은 다르다. 현재 비교 카메라를 보정 완료로 취급해서는 안 된다. 정밀 비례 검수에는 같은 화면비에서 실제 표시 시야각을 추가로 보정해야 한다. 이 관찰을 근거로 모델 치수를 바꾸지 않았다.
