## 목표와 고정 조건

첫 목표는 **액트 1에서 보이는 구간의 외형과 플레이 완성**이다. 전체 456동 정밀 제작은 후속 범위로 남긴다. 최근 교체한 35동과 주요 건물 8동은 모델 존재와 외관 검증을 별도로 기록한다.

- 흙길과 좁힌 도로는 사용자 지정 변경으로 유지한다.
- 기존 액트 연출·사요 모션을 건물 수정과 섞지 않는다.
- 다른 작업에서 수정 중인 지형·온천·공통 렌더링은 수정 전 현재 상태를 확인한다.
- 근거가 없는 면은 추정으로 표시한다. 사진의 건물과 필지 연결이 불확실하면 먼저 식별한다.
- 건물 수·테스트 통과 수를 원본 일치율로 표현하지 않는다.
- 매 묶음은 원본 확인 → 수정 → 같은 시점 비교 → 게임 검수 → 기록 갱신 순서로 마친다.
