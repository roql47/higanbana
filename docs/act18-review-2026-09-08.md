# 전체 재점검과 ACT 18 — 2026-09-08

기존 최적화·공동묘지·여관·촌장집 변경을 보존한 상태에서 진행 게이트, 조사 입력, 이어하기, 모델 자원 수명과 다음 액트 연결을 재점검했다. 기존 빌드는 ACT 17 종료 화면에서 멈췄다. 이번에는 ACT 18 「퀘스트를 준 자」를 실제 플레이 구간으로 연결했다.

## 수정 및 추가

| 영역 | 반영 내용 |
| --- | --- |
| 액트 진행도 | 분실한 봉인패를 다시 주웠을 때 ACT 16으로 돌아가던 경로를 막았다. 획득 이벤트는 현재보다 뒤의 액트로만 전진하며, 거절 이후 재획득은 최초 기억 연출을 반복하지 않는다. |
| ACT 17 → 18 | 봉인패 거절·목표창 변조 뒤 신사 동쪽 지하 입구를 안내한다. 기존 ACT 17 완료 저장도 여기서 이어진다. 이전 추격의 등불 위협도와 축제 음악 상태를 정리한다. |
| 지하 탐색 | 가동 격자 뚜껑, 방향을 바로잡은 사다리, 하강·상승 상호작용, 서쪽 모퉁이·북쪽 통로 안내를 연결했다. 뿌리·공중 붓글씨·공물 빈자리의 세 흔적을 자유 순서로 조사한다. |
| 히간누시 | 기존 흰 기모노 모델에 피안화 얼굴을 결합했다. 별도 상자형 팔 대신 실제 소매·손을 정점 셰이더로 함께 움직인다. 전용 최종 캐릭터 모델을 새로 제작한 것은 아니다. |
| 목표와 공물 | 「마지막 공물을 바쳐라」가 실제 공간에 표시된다. 이미 봉납한 다섯 공물이 뿌리에 붙들려 내려오고 이전 제단의 실물과 표식은 숨긴다. 봉납 수와 봉인패 소지는 유지한다. |
| 입력·복원 | 조사/이동/대면 중 인벤토리와 기록장 입력을 잠근다. 게임 시계로 하강 애니메이션을 정지·복귀한다. 조사 완료, 대면 시작, 공물 이동 완료, 장면 완료를 각각 저장한다. |
| 완료 뒤 | ACT 18 완료 화면에서 계속 탐색하거나 타이틀로 돌아갈 수 있다. 완료 저장은 대사를 반복하지 않고 공물 최종 위치를 복원한다. |

## 렌더링과 자원

- 지하 문과 촛대는 기존 지역 스트리밍 방식으로 접근 시 로드하고 이탈 후 해제한다. 캐릭터는 지하 진입/대면 시 한 번 준비하며 해당 실행 동안 유지한다.
- 공물은 기존 원형 모델의 geometry·material·texture를 공유한다. 이전 제단에서 늦게 모델 로드가 완료되더라도 숨김 상태를 유지한다.
- 긴 뿌리는 정적 geometry로 합치고, 움직이는 뿌리 15구간은 하나의 `InstancedMesh`로 그린다. 행렬은 하강/복원 시에만 갱신한다.
- 별도 광원이나 렌더 타깃은 추가하지 않았다. 기모노 제스처는 스칼라 uniform 하나로 제어한다.
- GPU/RAM 절감률이나 패키징 후 요구 메모리를 측정한 결과는 아니다.

## 검증

- 자동 회귀 테스트 **84개 통과**. 추가 4개는 진입 게이트·자유 조사 순서·입력 중복·중단 복원·공물 이동 완료 경계·완료 후 탐색을 검증한다.
- 타입 검사와 `BASE_PATH=/higanbana/ npm run build` 통과. 메인 JS 약 **5.02 MB**, gzip 약 **1.82 MB**이며 기존 청크 크기 경고는 남아 있다.
- 사용자 저장과 분리된 `127.0.0.1:5187`에서 실제 E 입력과 W 보행으로 하강 → 서쪽/북쪽 통로 → 세 조사 → 대면 → 완료 → 상승 → 봉인패 재획득을 확인했다.
- 첫 조사 후 재실행, 대면 시작 직후 재실행, 공물 하강 중 Esc 정지/복귀, 완료 후 재실행을 검증했다. 공물 위치·봉납 수·봉인패 소지와 늦게 로드된 제단 모델의 숨김을 확인했다.
- ACT 16의 봉인패를 실제 제단에 제시하여 거절 연출 → ACT 17 완료 → ACT 18 안내로 진행했다. ACT 17 완료 저장에서 바로 ACT 18로 넘어가는 경로도 확인했다.
- 학교·여관·촌장집·신사 지하의 접근 로드 → 이탈 해제 → 재진입 로드를 확인했다. 지하에서는 외부 지형이 숨겨진다.
- low 및 high 화면에서 모델·글씨·공물 배치와 셰이더를 확인했다. 화질 변경 시 기존 조명 풀 슬롯 수가 바뀌면서 재컴파일 경고가 한 번 발생했다. 개발 중 페이지 재로딩/탭 교체 시점에는 GLB 요청 실패 경고도 있었으며, 이후 새 페이지에서 다섯 공물 로드와 전체 진행 검사가 통과했다. 마지막 ACT 17→18 전환 검사 로그에는 경고·오류가 없었다.

검증용 실행 화면은 로컬 `artifacts/screening/act18.html`이다. 기존 QA 산출물과 함께 Git 제외 대상이며 게임에 포함하지 않는다.

## 현재 경계와 다음 작업

현재 플레이 연결은 ACT 18까지다. ACT 16의 과거 맵/사요 조작, ACT 17의 귀신 집결/일기 등 원안 일부는 여전히 미구현이다. 메타데이터에도 ACT 16~17은 `partial`, ACT 18은 `playable`, ACT 19~35는 `planned`로 기록한다.

다음 개발 지점은 **ACT 19 「자매의 재회」**다. ACT 18 마지막의 「하지 마」와 내려온 공물, 소지 중인 봉인패를 이어받아 사요 등장·손의 반응·침묵을 중심으로 연결해야 한다. 후반 복원·선택·엔딩과 Windows/Steam 패키징 검증은 남아 있다. 이번 확인은 모든 액트의 처음부터 끝까지 완주나 Steam 실행 파일 검증을 뜻하지 않는다.
