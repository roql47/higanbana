# 우물·묘지 플레이 문제 수정 — 2026-09-09

이 문서는 앞선 버그 수정 기록이다. 후속 실물 모델·최신 패키지·원본 앱 갱신은 [우물 물증·게다 묘역 아트 마감](./well-geta-art-2026-09-09.md)을 따른다.

사용자가 보고한 우물의 정지된 귀신, 환자복과 벽감 겹침, 맥락 없는 카메라 이동, 묘지 아이의 회전, 숨은 묘역의 의도하지 않은 귀환과 안내 부족을 수정했다. 기존 진행 데이터 형식과 공물·단서 조건은 유지했다.

## 우물

- 원인: `main.ts`의 `!cine` 구간 안에서만 `WellWoman.update()`를 호출해 연출 중 AnimationMixer까지 멈췄다. 이제 시각 업데이트를 매 게임 프레임 실행하고, 추격·포획·상태 주기의 시간만 따로 멈춘다. 일시정지 메뉴에서는 기존대로 전체 업데이트가 정지한다.
- 상승 클립을 고정 1.45초에 끊던 처리를 실제 클립 재생 완료 기준으로 바꿨다. 목마 확인의 지연 동작도 게임 프레임 시간으로 실행한다.
- 조약돌/지상 단서가 없어 탈출 선택지가 하나일 때 `Dialogue.choose`의 2~4개 조건에 걸려 진행이 멈추는 오류도 발견했다. 이때는 유일한 목소리 분기로 이어지게 했다.
- 등반 시작부터 포획 AI를 멈춰 매듭 대사에 포획 숏이 끼어들지 않게 했다. 마지막 매듭은 수면 위 상태와 `rope_tug` 동작을 명시적으로 시작하며, 선택지를 읽는 동안 가짜 하루가 사라지지 않는다.
- 벽감 모델의 원래 위치는 뒷벽 안쪽 면과 일치했고 +Z 앞면이 벽을 향했다. 물증만 42cm 앞으로 빼고 방 중앙을 향하게 했다. 환자복은 두께, 부드러운 주름, 직물 무늬와 젖은 밑단을 보강했다. 소매와 목마는 수면 위 선반에 놓고 선반 폭·깊이에 맞게 모델을 제한했다. 안전 벽감/조사 판정 위치는 유지했다.
- 별도 원인: 벽 각인 평면이 원형 방의 실제 벽 방향과 맞지 않아 환자복 앞을 가로질렀다. 온전한 벽 세그먼트의 안쪽 면에 맞춰 위치·각도·크기를 조정하고 조사 위치도 함께 옮겼다.
- 우물 카메라 키를 벽에서 65cm 안쪽에 제한하고, 키 사이를 벗어나지 않는 보간을 사용한다. 지상 결말은 먼 스피커로 날아가지 않고 우물가에서 소리를 듣는 구도로 변경했다. 연출 전 시점 방향을 기억하고 0.55초에 걸쳐 복귀한다. 하강 직후 카메라 피벗과 월드 가시성을 새 위치에 맞추고, 지상 결말을 암전이 가리지 않게 했다.

## 공동묘지

- 아이의 루트 전체에 높이가 다른 `lookAt`을 적용하던 것을 수평 회전으로 교체했다. 70cm 안에서는 방향을 유지하고, 초당 최대 1.25rad의 최단 호 회전으로 제한한다. 접근은 1.15m에서 멈추며 프레임이 길어져도 지나치지 않는다. 지하 플레이어를 지상 아이가 따라가지 않는다.
- 지상 미로의 XZ 경계 검사가 지하 공간을 지상으로 끌어올릴 수 없도록 실제 지면과의 높이 조건을 추가했다. 숨은 묘역의 바닥/외곽 이탈은 같은 묘역의 안전한 입구로 복구한다. 정상 귀환은 붉은 매듭 문에서 E를 길게 누르는 기존 명시적 상호작용으로 진행한다.
- 24×26m 보행 공간과 기존 퍼즐을 유지했다. 높은 방 같은 담장/칸막이를 낮추고, 바닥·석재 텍스처와 약한 재질 발광, 석등으로 길을 읽게 했다. 추가 동적 광원은 없다.
- 진입 안내에 앞마당 발자국 → 오른쪽의 왼쪽 게다 → 세 길에서 짝 찾기 → 붉은 매듭에서 E 길게 눌러 귀환 순서를 추가했다. HUD 구역 판정에 숨은 묘역을 독립적으로 넣었다.

## 검증

- 타입 검사 및 전체 자동 테스트 **102개** 통과. 추가 회귀 검증: 연출 중 뼈대 움직임과 AI 정지, 근접 회전과 최단 호, 지하에서 지상 미로 금지와 동일 묘역 복구, 우물 카메라 경계, 1/3인칭 복귀 방향.
- 격리한 로컬 게임에서 실제 두 번째 벽감 조사로 대면 숏을 시작했다. `face_check` 시간이 0.0334초에서 0.7167초로 진행했고 뼈대 쿼터니언 변화 합이 2.0627, AI 위치 변화는 0이었다. 숏 종료 뒤 카메라도 석실 안에 유지됐다.
- 실제 등반에서도 포획 숏의 개입 없이 마지막 매듭의 `rope_tug` 재생과 수면 위 상태를 확인했다. 준비물 없이 선택지가 하나만 남는 경로도 지상 우물 입구까지 정상 완료했다. 두 선택지가 있는 경로에서는 7.5초 동안 선택을 기다려도 아이가 보였고, 선택 후 같은 우물 입구로 복귀했다.
- 환자복, 젖은 소매, 목마를 각각 게임 1인칭 화면에서 확인했다. 글씨가 환자복 앞을 덮는 문제가 사라졌고 세 물증 모두 벽 앞에 보인다.
- 묘지 보행 검증: 시선 자리 진입, 바닥 착지, 발자국 조사, 공물 없는 조기 귀환, 재진입과 저장 재개, 왼쪽 게다 조사, 가짜 게다 후 단서 유지, 정답 판별과 공물 획득, 가짜 문 후 공물 유지, 운반 상태 저장 재개, 정상 귀환과 작별 기록까지 통과했다.
- Mac 별도 QA 앱에서 패키지 로딩과 ACT 2 이어하기, 미오·지면·나무의 텍스처 표시를 확인하고 게임 메뉴로 종료했다. 우물·묘지 전체 경로 검증은 브라우저 게임에서 수행했다. Windows 실기기 실행은 아직 검증하지 않았다.
- QA 재현 페이지: `artifacts/screening/well-scene-fixes.html`, `artifacts/screening/graveyard-hollow.html` (포트 5187에서만 테스트 세이브 조작 허용). 실제 사용자의 앱/프로필과 별개다.

현재 실행 중인 원본 Higanbana 앱은 변경하거나 종료하지 않았다. 새 Mac 실행본은 `release/macos-arm64/Higanbana.app`이며, 기존 앱을 종료한 뒤 새 실행본을 열어야 수정 코드가 실행된다. 기존 앱의 저장 프로필을 그대로 사용한다.
