# 촌장집 모델링·표면 마감

## 반영

- 결재함: 모서리 베벨, 인장판 테두리·축받이, 압인 받침, 볼트, 지렛대 연결부, 서랍 측판과 천 안감, 입체 손잡이. 열쇠와 인쇄지는 새 받침의 실제 높이에 맞췄다.
- 불단: 닫힌 문이 붙은 기존 GLB 대신 내부가 빈 목제 불단을 구성했다. 계단식 상부, 하부 패널, 안쪽 봉인패 받침과 황동 장식, 경첩·격자가 있는 가동 덮개가 한 구조를 이룬다. 봉인패의 공통 원통 받침은 제거하고 불단에 직접 놓는다.
- 조사 소품: 탁본판 가장자리와 고정핀, 섬유 결이 있는 꾸러미와 곡선 매듭, 깊이가 있는 빈 회신함과 명판, 여섯 봉인표와 실제로 비어 있는 일곱 번째 홈.
- 공간: 목재 마루 이음매, 흙벽과 낮은 판벽, 문틀·천장 보, 안방 다다미, 지하 석벽과 기둥, 서재 벼루·붓·인장.
- 가구 보정: 서가·책상·장롱·이불의 폭과 깊이를 기존 충돌 범위에 맞추면서 상판 높이를 유지한다. 지하 장부는 눕혀 상판에 올렸다. 봉인표 선반은 가구 스트리밍 후에도 유지하며 사다리 가로대가 양쪽 세로대에 연결되도록 수정했다.

## 재질과 비용

목재·흙벽은 기존 마을 PBR 맵, 지하 벽은 기존 석재 맵을 공유한다. 새 천 표면은 공유하는 128×128 색상·노멀 맵 한 벌이다. 인장판 12면은 기존 512×512 아틀라스 안에서 종이 섬유·때를 표현한다. 봉인표 원본의 지나치게 매끈한 표면도 조정했다.

고정 부품은 재질별로 병합하고 가동부의 피벗은 유지했다. 새 광원·반사 렌더 타깃은 없다. FPS/RAM 개선율은 측정하거나 주장하지 않는다.

## 검증

- 실제 E 입력: 대청 기록 → 세 단서 → 지하 이동 → 오답 출력 → 인장판 회전·중간 저장 복원 → 정답 출력·서랍 → 열쇠 → 상승 → 불단 개방 → 봉인패 → ACT16 세 기억 연결.
- 기존 봉인패 운반 저장의 덮개 개방·ACT16 진행과 사망 드롭 후 재획득 확인.
- 실제 화면에서 결재함·불단·서재·안방 꾸러미·회신함·봉인표·열람 탁자를 확인.
- `npm test`: 80개 통과. 가구 높이·바닥 정렬·충돌 범위와 메시 병합 후 피벗/경계 유지도 별도 기하 검사로 확인.
- `npm run typecheck`, `BASE_PATH=/higanbana/ npm run build` 통과. 기존 대형 메인 청크 경고는 남아 있다.

QA는 별도 포트 5187에서 수행하며 실제 플레이 포트의 저장 데이터는 사용하지 않는다.
