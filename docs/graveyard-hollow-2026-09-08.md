# ACT 12 · 지장의 시선 안쪽

공동묘지의 지상 조사 다음에 별도의 공간 탐색을 추가했다. 기존 사요와 손바닥 약속의 복선은 숨은 묘역에서 게다를 가지고 돌아온 뒤 이어진다.

## 플레이 흐름

1. 기존 돌탑·붉은 천·지장 단서를 조사하고 숨바꼭질의 두 판단을 마친다.
2. 서로 다른 두 지장의 얼굴을 조사하면 모든 시선이 같은 빈 자리를 향한다는 기록이 남는다. 관찰 기록 자체는 진입의 필수 조건이 아니다.
3. 여섯 지장의 시선이 모이는 자리에 잠시 서면 숨은 묘역으로 건너간다. 정답 자리에 목표 화살표를 붙이지 않는다.
4. 세 길의 맨발 자국과 남겨진 왼쪽 게다를 조사한다. 돌아오는 발끝, 붉은 끈의 푸른 수선 실, 닳은 뒤굽으로 진짜 짝을 판별한다.
5. 두 미끼 중 하나를 고르면 입구로 돌아온다. 정답을 대조한 뒤 별도의 E 입력으로 실제 공물을 집는다.
6. 언니 목소리가 들리는 가짜 문도 입구로 이어진다. 처음 들어온 붉은 매듭의 문을 짚고 지상으로 돌아온다.
7. 아이들이 사요를 언급하고 두 손의 약속을 전한다. 게다를 운반해 신사로 돌아가는 기존 공물 흐름이 이어진다.

게다를 얻기 전에도 나올 수 있다. 오답은 조사 기록과 운반품을 지우지 않는다. 묘역 안의 위치·단서·게다 운반 상태와 지상 귀환 직후의 미완료 작별 장면을 저장에서 복원한다. 진입 페이드 도중 저장되어 진입 기록이 빠졌더라도, 짝을 맞춘 기록으로 작별 장면을 이어간다. 기존 손바닥 장면을 끝낸 저장에는 새 조사 조건을 소급하지 않는다.

## 공간과 자원

- 지형 아래에 24×26 m 바닥과 세 갈래 통로를 만들고 고정 충돌을 붙였다. 지상 묘지 반복 판정과 추격 AI는 이 공간에 적용하지 않는다.
- 지하에 들어가면 기존 지상 렌더 그룹을 숨긴다. 숨은 묘역은 내부에 있을 때만 렌더링한다.
- 벽과 묘석은 재질·공간 셀별로 병합하고 발자국 84개는 인스턴스 메시 하나로 그린다. 입구부터 세 줄을 벌리고 아이의 크기와 보폭을 맞춰 방향이 겹쳐 보이지 않게 했다.
- 기존 돌 텍스처와 게다 모델을 재사용한다. 추가 광원·음성·GLB·후처리는 없다. 길의 윤곽은 약한 재질 발광으로 보강한다.
- 실제 게다와 절차적으로 만든 단서용 짝의 크기를 맞추고 받침대 표면에 놓았다. 세 귀환문의 접근로는 묘석 배치에서 제외한다.
- 지상 묘석의 희생자 수는 유지한다. 숨은 묘역의 묘석은 같은 묘석이 반복되는 공간 연출이다.

GPU/RAM 증가량과 초회 플레이타임 증가량은 측정하지 않았다. 새 공간과 탐색 과정이 생긴 만큼 비용과 플레이 분량이 추가된다.

## 검증 기록

자동 테스트 69개와 타입 검사가 통과했다. 새 상태 검사는 조사 조건, 서로 다른 지장 관찰, 미끼 두 종류, 조기 귀환, 단서 보존, 중복 진입 차단, 귀환 장면 중단·복원, 진입 페이드 중 저장을 다룬다.

브라우저 검증은 별도 `127.0.0.1:5187` 저장으로 수행한다. 지상 조사 완료 저장에서 시작하며 숨은 묘역의 통로는 실제 W 이동과 E 상호작용으로 통과한다. 진입 재현에만 지상 시작 위치 이동을 사용하고, 자막은 빠르게 재생한다. 이 시간은 실제 플레이타임 측정값이 아니다.

최종 브라우저 경로가 통과했다: 시선 자리 자동 진입·착지·지상 컬링 → 발자국 조사 → 게다 없이 조기 귀환 → 재진입·단서가 있는 저장 재개 → 남겨진 짝 조사 → 가짜 게다 선택과 입구 복귀 → 진짜 짝 판별·공물 획득 → 가짜 귀환문과 운반품 보존 → 운반 중 저장 재개 → 붉은 매듭 귀환·손바닥 장면·귀환 기록 저장. 이 과정에서 발견한 귀환문 앞 묘석 충돌을 수정한 뒤 같은 경로를 다시 통과했다. 최종 브라우저 경고·오류 로그는 없었다.

낮음 품질의 1인칭 근접 화면에서 발자국의 방향과 천 위 게다를 확인했다. 입구의 발자국 세 줄이 겹치던 배치를 분리하고 보폭을 조정한 후, 발끝·뒤꿈치가 따로 읽히는 것을 재확인했다.

`/higanbana/` 경로의 배포용 빌드와 `git diff --check`도 통과했다. 기존 메인 청크 크기 경고는 남아 있다. 전체 액트 완주와 초회 사용자의 퍼즐 난이도 검증은 별도다.
