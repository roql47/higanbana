# 추가 최적화 — 2026-09-09

긴 환경음 두 개를 구간 디코딩 방식으로 바꾸고, 여관·촌장집의 벽에 완전히 가려진 실물 가구를 메인 렌더에서 생략한다. 전체 게임의 FPS, 프로세스 RAM/VRAM, Windows 권장 사양은 이번 수치로 확정하지 않는다.

## 환경음

- `amb/frogs` 47초와 `amb/higurashi` 80초를 6초 FLAC 구간으로 나눴다. 원본을 전체 디코딩한 24-bit PCM과 분할 파일을 이어 디코딩한 PCM은 바이트 단위로 같았다. 새 음원 합성, 길이 축소, 모노 변환은 하지 않았다.
- 최초 구간만 미리 디코딩하고 다음 구간을 선읽기한다. AudioContext 시간으로 연결하며 구간 경계·원래 루프 순서를 유지한다. 예약 직전에는 이전/현재/다음 구간이 잠시 겹쳐 상주할 수 있다.
- 오디오 스레드의 루프를 다음 구간 예약까지 유지한다. 메인 스레드가 셰이더 컴파일·GC 등으로 오래 멈춰도 마지막 구간이 반복되며, 늦게 복구하면 50ms 페이드로 연결한다. 이 상황에서는 원본의 시간 진행이 지연될 수 있다.
- AudioContext 일시정지 중에는 예약이 누적되지 않는다. 종료 후 소스·게인·PCM 참조를 해제하고, 뒤늦은 읽기 완료도 보관하지 않는다.
- 구간 디코더가 실패하거나 길이를 잘못 반환하면 최초 준비 단계에서 기존 전체 MP3로 돌아간다. 짧은 효과음·scatter 루프·공간 패너·실내 필터·덕킹은 기존 경로를 유지한다.
- 테스트 브라우저의 48kHz stereo 기준 두 음원 전체 PCM은 계산상 **46.51MiB**다. 실제 구간 재생의 PCM 참조 합계는 보통 **8.79MiB**, 1초 간격 관찰에서 최대 **13.18MiB**였다. 관찰한 최대값 기준 약 **33.33MiB 감소**이며, 전체 프로세스 RAM 측정이나 절대 상한이 아니다. 디코더 내부 임시 메모리·GC 회수 지연은 이 통계에 포함되지 않는다.
- 두 스트림이 199초 이상의 AudioContext 시간 동안 유지되고 원래 길이를 넘어 반복하는 것을 확인했다. 일시정지 동안 AudioContext 시간 83.584초와 예약 수 22개가 고정됐고, 재개 후 예약이 이어졌다. 종료 시 두 스트림의 PCM·활성 키가 0이 됐다. 자동 테스트는 샘플 순서·지연 복구·종료 참조 해제를 검사한다.
- 분할 FLAC 파일 합계는 **14,915,228 bytes (14.22MiB)**다. 원본 MP3는 호환 폴백용으로 보존하므로 설치 용량은 그만큼 늘어난다. 원본 변경 시 `npm run audio:fetch` 다음 `npm run audio:segment`를 실행한다. 분할 스크립트에 FFmpeg/ffprobe가 필요하며 일반 빌드에는 필요 없다.

## 실내 가림 처리

- 여관·촌장집의 실제 벽/천장을 만들 때 불투명한 고정 박스의 내부 경계를 기록한다. 대상은 스트리밍된 실물 가구이며 건물 전체·학교·동적 인물은 이 변경의 대상이 아니다.
- 가구 경계 상자의 여덟 꼭짓점 모두가 **같은 벽**에 가려질 때만 후보로 삼는다. 서로 다른 벽 조각을 조합해 문틈을 가렸다고 오판하지 않는다. 벽 경계는 줄이고 대상 경계는 넓혀 문턱에서 보수적으로 판정한다.
- 화면 밖 가구의 그림자가 다른 방에 나타날 수 있으므로, 활성 그림자 광원에서 여전히 보이는 가구는 유지한다. 점광원 거리와 방향광의 평행 광선을 구분한다.
- 메인 후처리 렌더 동안만 숨기고 `finally`에서 복원한다. 손거울의 별도 세계·모델 소유권·충돌·스토리 진행·아이템 획득 상태를 변경하지 않는다.
- 40m 밖에서는 이 판정을 생략한다. 가구의 로컬 경계는 WeakMap으로 보관하므로 해제된 모델을 붙잡지 않는다.

실제 게임 장면을 고정 카메라, High 설정, 별도 테스트 등불, 600×400 렌더 타깃으로 비교했다. 모든 그림자를 두 렌더에서 동일하게 갱신했다. 후처리 이전 RGBA 픽셀 비교이며 일반 플레이 전체 FPS 벤치마크가 아니다.

## 검증과 배포

- 자동 테스트 97개와 게임/scripts 타입 검사 통과. 마지막 지역 이탈 메타데이터 정리 변경 후 관련 오디오 테스트 7개 재통과.
- 데스크톱 콘텐츠 빌드·전체 음원 및 구간 파일 존재 검사 통과. 기존 main 청크 크기 경고는 남아 있다.
- Windows x64와 macOS arm64 패키지에 최신 콘텐츠를 반영한다. 네이티브 셸 코드는 변경하지 않았다. Mac 스테이징은 최신 콘텐츠를 복사하고 로컬 ad-hoc 서명을 다시 검사하므로 이전 앱 번들의 오래된 웹 파일을 배포하지 않는다.
- 별도 식별자 `com.higanbana.optimizationqa`의 Mac 네이티브 검증 앱에서도 두 스트리밍 루프 시작 로그를 확인했다. 호환 폴백 없이 FLAC를 디코딩했고, 사요 모델·지면·나무·건물의 정상 텍스처를 화면으로 확인했다. 기존 플레이 앱과 저장 프로필은 분리했다.
- Windows 실기기 검증, 전체 액트 완주, GPU 사양 등급별 성능 측정은 수행하지 않았다. GPU 압축 확대·고정 조명 베이크·학교 가시성은 추가 후보로 남아 있다.

최종 패키지: Windows ZIP 82,626,669 bytes, 360개 파일(설치 파일 합계 93.46MiB); Mac ZIP 81,114,701 bytes, 361개 파일(92.80MiB). 파일별 SHA-256·크기, ZIP 무결성, Mac ad-hoc 서명 검증 통과.
