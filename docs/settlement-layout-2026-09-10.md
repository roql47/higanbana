# 마을 구성 1차 — 중심 거리, 주거 골목, 외곽 농가

## 원인

기존 결정적 민가 배치를 실제 지형에 실행하면 8채만 생성됐다. 후보 17개는 부지, 16개는 도로 충돌로 제외되어 목적지 사이에 주거 밀도가 부족했다. 기존 8채는 생활 흔적과 획득용 등불의 앵커이므로 좌표와 순서를 보존했다.

## 순차 반영

1. 중심 거리: 기존 본거리 민가 두 채의 외관을 닫힌 가게로 보강하고, 지도상 남쪽(z+)으로 가게 한 채와 앞길을 추가했다. 간판·진열대·빈 나무 상자·작은 차양을 공유 재질로 배치했다.
2. 주거 구역: 동쪽과 우물 뒤에 주거 집터와 연결 길을 만들었다. 낮은 측면 담장·툇마루·뒤쪽 건조대 등으로 집터 경계를 드러냈다. 새 동쪽 민가는 기존 처마에 닿지 않도록 4×4 m로 줄이고 위치를 조정했다.
3. 외곽 전환: 남쪽 대숲길 가까이에 농가와 헛간을 한 쌍으로 배치하고 진입길·농작업 받침·장대 거치대를 추가했다.

총 민가 17채(기존 8 + 계획 9). 이는 여관·학교 등 별도 액트 건물 수를 포함하지 않는다. 신규 연결 골목은 4개이며 기존 다섯 순찰 경로와 기존 LANES의 종점은 유지했다. 가게 외관은 진입 가능한 새 액트가 아니다.

집터 데이터는 `settlementPlan.ts`가 소유하며 지형 평탄화·식재 제외·건물 배치에서 공유한다. 집터는 둥글게 원지형과 연결되고 다져진 흙으로 정점색을 보강했다. 길 가장자리 일부에 낮은 연속 배수 경계석을 두되 교차점은 비운다.

## 검증과 범위

- 타입 검사, 전체 테스트, desktop 빌드 통과.
- 신규 부지와 도로/액트 부지의 간섭, 기존 8채 위치 보존, 새 길과 기존 건물 간격, 처마 1 m/툇마루 1.2 m를 포함한 새 건물 간 분리, 기초 모서리 높이를 자동 검사.
- 실제 Hamlet/지형/재질을 사용하는 별도 브라우저 장면에서 전체 배치, 중심 거리, 주거지, 농가 외형 확인. 실제 밤 조명·모든 액트 보행/추격전의 통합 검수는 이번 작업에서 수행하지 않았다.
- 정적 구조물은 재질별 병합, 기존 텍스처 공유. 새 간판은 공유 256×96 캔버스 한 장. 새 점광원/그림자 광원 없음. 전체 게임 FPS·RAM 측정은 하지 않았다.
- Mac/Windows 스테이징과 preview ZIP 갱신. 최신 frontend `main-B2v4iy5A.js`.

다음 외형 검토는 실제 야간 게임에서 광장·우물 접근 시 보이는 거리의 연속성과 랜드마크 시야를 기준으로 진행할 수 있다. 이번 변경은 마을의 공간 구성을 만드는 첫 번째 작업이다.
