# 여관 액트 · 거울과 조사 소품 보완

왕복 상호작용은 있었지만 객실2 쪽에만 거울이 있어, 거울 방에서 돌아오는 지점은 맨벽으로 보였다. 양쪽 벽면에 입체 목재 프레임·모서리 금구·안쪽 유리를 배치하고 복도 거울도 같은 모델 구성으로 바꿨다. 양면의 조사 위치와 바라보는 방향을 각각 모델에 맞췄다.

깨진 거울을 운반할 때는 안쪽 귀환 거울을 안내한다. 귀환하면 제단 안내로 돌아가며, 이동할 때마다 위치를 저장한다. 기존 저장이 거울 방 안에 있더라도 새 선행 조사 조건 때문에 귀환을 막지 않는다. 와쿄를 들고 거울을 마주 보는 조건은 양쪽 모두 유지한다.

## 빠져 있던 소품과 배치

- 와쿄 속 신발장·병풍·화로·우산을 실제 방과 같은 모델·위치로 복제했다.
- 경대와 공물 받침도 셸에서 로드한 실제 모델을 공유한다. 로드 실패 시 기존 형태를 유지한다.
- 큰 거울 복제본의 유리가 실제 벽면보다 약 50cm 앞으로 나와 있던 좌표와 프레임 위치를 맞췄다.
- 숙박부 GLB를 접수대에 추가했다. 기울어져 제작된 원본은 로드 시 한 번 주축을 계산해 눕히고, 책등 두께와 바닥 접촉을 맞춘다. 모델이 없을 때도 제본·페이지가 있는 책 형태가 남는다.
- 반납 열쇠와 받침, 짐표와 늘어진 끈, 마주 거울까지 이어지는 끌린 짐 자국을 추가했다.
- 접수대·좌탁의 모델 폭을 제한한 뒤에도 상판 높이를 유지하도록 했다. 와쿄도 좌탁에 붙여 놓았다.
- 와쿄 획득 상태를 모델 로드 완료 후에도 적용해, 이어하기 중 늦게 도착한 모델이 다시 나타나는 문제를 수정했다.

## 자원과 검증

새 광원이나 거울 반사 렌더 타깃은 추가하지 않았다. 세 벽거울의 현실·과거 모델은 지오메트리를 공유하며, 기존 GLB를 복제해 사용한다. 거울 은막 표면만 작은 캔버스 텍스처 두 장을 생성한다. GPU/RAM 변화는 측정하지 않았다.

자동 테스트 71개가 통과했다. 기울어진 책의 정렬·바닥 접촉·두께 제한과 양쪽 프레임 안의 정면 유리 교차 검사를 추가했다. 타입 검사와 `/higanbana/` 경로의 배포용 빌드도 통과했다. 기존 메인 청크 크기 경고는 남아 있다.

별도 `127.0.0.1:5187` 저장으로 다음을 확인했다. 위치 재현에는 테스트용 이동을 사용했고, 와쿄 획득과 통로는 실제 W/V/E 입력으로 검사했다.

- 현실과 와쿄 속 거울·가구 8종 및 경대 모델 일치.
- 좌탁에서 와쿄 획득 → 이어하기 → 뒤늦은 모델 로드 후에도 재등장하지 않음.
- 벽을 걸어서 관통할 수 없고, 와쿄 없이 사용하거나 등지면 통과하지 않음.
- 진입 거울 → 거울 방 → 안쪽 귀환 거울 → 객실로 복귀.
- 거울 방 안에서 이어하기한 뒤 귀환.
- 공물 운반 저장 → 귀환 거울 안내 → 공물을 유지한 실제 귀환 → 제단 안내 복귀.

낮음 품질의 실제 화면에서 귀환 거울의 프레임·유리, 접수대 위에 눕힌 숙박부, 객실 짐표와 끈을 확인했다. 최종 브라우저 경고·오류 로그는 없었다. 이 검증은 여관 전체 액트의 연속 완주 검증은 아니다.
